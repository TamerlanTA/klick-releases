# Klick — скачать

Klick — ИИ-ассистент, который выполняет задачи на вашем компьютере: голосом или текстом.

## Скачать последнюю версию

| Компьютер | Файл |
|---|---|
| Mac с чипом Apple (M1, M2, M3, M4) | [Klick-mac-arm64.dmg](https://github.com/TamerlanTA/klick-releases/releases/latest/download/Klick-mac-arm64.dmg) |
| Mac с процессором Intel | [Klick-mac-x64.dmg](https://github.com/TamerlanTA/klick-releases/releases/latest/download/Klick-mac-x64.dmg) |
| Windows 10 и 11 (64-бит) | [Klick-Setup.exe](https://github.com/TamerlanTA/klick-releases/releases/latest/download/Klick-Setup.exe) |

Какой у вас Mac: меню  → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

## Как установить на Mac

1. Откройте скачанный файл `.dmg` и перетащите **Klick** в папку **«Программы»**.
2. Откройте Klick из «Программ». macOS спросит, открыть ли приложение, загруженное из интернета, — нажмите **«Открыть»**. Klick подписан и проверен Apple.
3. В окне Klick нажмите **«Войти через браузер»**. На сайте [sayklick.app](https://www.sayklick.app) войдите (Google или почта и пароль; если аккаунта нет — «Создать аккаунт») и нажмите **«Подключить»**. Браузер спросит, открыть ли Klick, — разрешите.
4. Дайте Klick разрешения, когда он попросит (или в «Конфиденциальность и безопасность»):
   - **Микрофон** — для голосовых команд;
   - **Универсальный доступ** — чтобы управлять мышью, клавиатурой и приложениями;
   - **Запись экрана** — чтобы видеть экран.

   После выдачи разрешений перезапустите Klick.

Готово: напишите задачу в окне Klick или нажмите **⌘⇧Space**. Голосовой разговор — **⌘⇧J**, остановить задачу — **⌘⇧X**.

## Как установить на Windows

1. Запустите скачанный `Klick-Setup.exe`. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае»: сборка пока без цифровой подписи.
2. Klick установится без прав администратора и откроется сам. Войдите так же, как на Mac (шаг 3 выше).

На Windows вместо ⌘ — Ctrl: задача — **Ctrl+Shift+Space**, голос — **Ctrl+Shift+J**, остановить — **Ctrl+Shift+X**.

## Обновление

С версии 0.2.13 Klick обновляется сам. Когда выйдет новая версия, он скачает её в фоне, проверит и покажет кнопку **«Перезапустить и обновить»**: Klick закроется и через несколько секунд откроется уже новым. Вход, память и чаты сохранятся. Если во время задачи — обновится, когда она закончится. Если само не получится, будет кнопка «Скачать»: поставьте новую версию поверх старой.

С 0.2.12 и раньше на 0.2.13 нужно перейти вручную, последний раз: скачайте её по ссылке выше и поставьте поверх. На Mac после этого macOS один раз попросит заново включить «Универсальный доступ» и «Запись экрана» и может спросить пароль от Mac для «Klick Safe Storage» — нажмите **«Разрешить всегда»**.
