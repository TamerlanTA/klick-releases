# Klick — скачать

Klick — ИИ-ассистент, который выполняет задачи на вашем компьютере: голосом или текстом.

| Компьютер | Файл |

Какой у вас Mac: меню  → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

## Как установить на Mac

1. Откройте скачанный файл `.dmg` и перетащите **Klick** в папку **«Программы»**.
2. Откройте Klick из «Программ». Первый раз macOS скажет, что **не может проверить приложение** — это нормально: сборка пока без подписи Apple. Нажмите «Готово».
3. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **«Всё равно открыть»** рядом с Klick, затем подтвердите паролем. Это нужно сделать один раз.
4. В окне Klick нажмите **«Войти через браузер»**. На сайте [sayklick.app](https://www.sayklick.app) войдите (Google или почта и пароль; если аккаунта нет — «Создать аккаунт») и нажмите **«Подключить»**. Браузер спросит, открыть ли Klick, — разрешите.
5. Дайте Klick разрешения, когда он попросит (или в «Конфиденциальность и безопасность»):
   - **Микрофон** — для голосовых команд;
   - **Универсальный доступ** — чтобы управлять мышью, клавиатурой и приложениями;
   - **Запись экрана** — чтобы видеть экран.

   После выдачи разрешений перезапустите Klick.

Готово: напишите задачу в окне Klick или нажмите **⌘⇧Space**. Голосовой разговор — **⌘⇧J**, остановить задачу — **⌘⇧X**.

## Обновление

Когда выйдет новая версия, Klick покажет строку «Вышла новая версия» с кнопкой «Скачать». Поставьте новую версию поверх старой так же — вход, память и чаты сохранятся.
