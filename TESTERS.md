# Klick 0.2.10 — инструкция для тестировщиков

Обновлено 19.11.2026, версия 0.2.10.

Klick — ИИ-ассистент, который сам выполняет задачи на вашем компьютере: по тексту или голосом. Версия 0.2.10 тестовая, для Mac и Windows. Ниже — как её поставить, подключить и с чего начать.

## 1. Скачать и установить

Скачайте файл для своего компьютера. Какой у вас Mac: меню  → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

| Компьютер | Файл |
| --- | --- |
| Mac с чипом Apple (M1, M2, M3, M4) | [Klick-mac-arm64.dmg](https://github.com/TamerlanTA/klick-releases/releases/download/v0.2.10/Klick-mac-arm64.dmg) |
| Mac с процессором Intel | [Klick-mac-x64.dmg](https://github.com/TamerlanTA/klick-releases/releases/download/v0.2.10/Klick-mac-x64.dmg) |
| Windows 10 и 11 (64-бит) | [Klick-Setup.exe](https://github.com/TamerlanTA/klick-releases/releases/download/v0.2.10/Klick-Setup.exe) |

Страница версии: [Klick 0.2.10 (тестовая)](https://github.com/TamerlanTA/klick-releases/releases/tag/v0.2.10). Уже стоит 0.2.9 — поставьте 0.2.10 поверх: вход, память и чаты сохранятся.

**Windows.** Запустите `Klick-Setup.exe`. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае»: сборка пока без цифровой подписи. Klick установится без прав администратора и откроется сам.

**Mac:**

1. Откройте скачанный `.dmg` и перетащите **Klick** в папку **«Программы»**. Если Klick уже стоит, замените старую версию: вход, память и чаты сохранятся.
2. Откройте Klick из «Программ». В первый раз macOS скажет, что **не может проверить приложение**: сборка пока без подписи Apple. Нажмите «Готово».
3. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **«Всё равно открыть»** рядом с Klick, подтвердите паролем. Это нужно один раз.
4. Снова откройте Klick из «Программ».

## 2. Войти

При первом запуске Klick покажет окно «Привет, я Klick».

1. Нажмите **«Войти через браузер»**. Откроется сайт [sayklick.app](https://www.sayklick.app).
2. Войдите через Google или по почте. Если аккаунта нет, нажмите «Создать аккаунт».
3. Нажмите **«Подключить»**. Браузер спросит, открыть ли Klick, — разрешите. Klick подключится сам.
4. Если Klick не открылся, скопируйте код со страницы и вставьте его в Klick через **«Вставить код из браузера»**.

Есть приложение Klick на телефоне? Тогда можно иначе: в телефоне «Компьютер» → «Подключить», а в Klick на Mac — **«Есть код из приложения Klick»** и 6-значный код. После этого задачи можно давать и с телефона.

Новый аккаунт получает бесплатный доступ до открытия оплаты.

## 3. Разрешения

**Windows:** отдельных разрешений не нужно. Если Klick не слышит вас, включите доступ к микрофону для приложений: «Параметры» → «Конфиденциальность и защита» → «Микрофон».

**Mac:** без трёх разрешений Klick не сможет слышать вас, видеть экран и работать с приложениями. Все три включаются в **Системные настройки → Конфиденциальность и безопасность**.

| Разрешение | Зачем |
| --- | --- |
| Микрофон | голосовые команды и слово «Клик» |
| Универсальный доступ | управлять мышью, клавиатурой и приложениями |
| Запись экрана | видеть, что на экране |

- Klick сам попросит нужное. Если чего-то не хватает, в его окне появится плашка с кнопками, которые открывают нужные настройки.
- После того как включили разрешения, нажмите «Перезапустить Klick» или закройте и снова откройте его.
- После каждого обновления Klick macOS может сбросить «Универсальный доступ» и «Запись экрана»: сборка без подписи Apple выглядит для неё новым приложением. Если Klick в списке уже включён, но не работает, удалите его из списка кнопкой «−» и добавьте заново.

## 4. Как давать задачи

Задачу можно написать или сказать обычными словами, как человеку. Klick сам решает, что открыть и куда нажать, и показывает ход работы.

- **В окне Klick.** Нажмите «Новый чат», напишите задачу и нажмите Enter. В чате можно уточнять: «а теперь отправь ему ещё раз».
- **Быстрая команда из любого места.** Нажмите ⌘⇧Space, напишите задачу в маленькой строке. Ответ Klick может произнести голосом.
- **Голосом через «Клик».** Включите «Настройки» → «Слушать „Клик“». Теперь скажите «Клик» и задачу, например «Клик, открой почту». Работает и при закрытом окне.
- **Разговор без слова «Клик».** Нажмите ⌘⇧J или «Голосовой ассистент» в левом нижнем углу окна. Чтобы закончить, попрощайтесь: «Ладно, пока».

Перед действиями, которые нельзя отменить (отправить, удалить, опубликовать), Klick спрашивает подтверждение. Ответьте «да» или «нет» — голосом или кнопкой. Задачи идут по одной: новая ждёт, пока закончится текущая.

| Mac | Windows | Что делают |
| --- | --- | --- |
| ⌘⇧Space | Ctrl+Shift+Space | быстрая команда |
| ⌘⇧J | Ctrl+Shift+J | голосовой разговор |
| ⌘⇧X | Ctrl+Shift+X | остановить текущую задачу |
| ⌘N | Ctrl+N | новый чат |

Ниже в тексте клавиши указаны для Mac; на Windows вместо ⌘ — Ctrl.

## 5. Примеры задач

Начните с простого, потом пробуйте задачи из своей работы.

| Что нужно | Как сказать или написать |
| --- | --- |
| Сообщение | «Клик, напиши Алие в WhatsApp: буду через полчаса» |
| Найти в интернете | «Найди три кофейни рядом с метро Алатау с рейтингом выше 4,5» |
| Открыть и настроить | «Открой почту и покажи непрочитанные письма» |
| Таблица | «Сделай таблицу Excel с расходами за неделю и сохрани на рабочий стол» |
| Презентация | «Сделай презентацию из 5 слайдов про наш новый продукт» |
| Картинка | «Нарисуй баннер для инстаграма с кофе и круассаном» |
| По расписанию | «Каждое утро в 9:00 присылай погоду и курс доллара» |
| Запомнить | «Запомни: мою жену зовут Айгерим, она в WhatsApp как «Айгерим»» |

Чем точнее задача (кому, что, куда сохранить), тем быстрее и дешевле она выполняется.

## 6. Разделы окна и настройки

Слева в окне Klick — разделы, внизу — «Настройки».

| Раздел | Что там |
| --- | --- |
| Задачи | всё, что Klick делал: из чата, голосом, с телефона, по расписанию |
| Проекты | большие задачи из нескольких шагов: бриф, шаги, проверенные результаты |
| Расписания | повторяющиеся задачи (каждое утро, по будням) и ваши быстрые команды |
| Навыки и память | что Klick знает о вас и чему научился; лишнее можно удалить |
| Чаты | ваши разговоры с Klick, есть поиск |

В «Настройках» стоит сразу заглянуть в эти пункты:

- **Лимиты** — сколько израсходовано за неделю. Лимит обновляется в понедельник в 00:00 (по Алматы).
- **Слушать «Клик»** — включает пробуждение по слову «Клик».
- **Голос и темп речи** — выберите голос Klick и нажмите «Послушать». Голос можно сменить и словами: «Клик, смени голос».
- **Как к вам обращаться** — имя, которое Klick использует в разговоре.
- **Запускать при входе** — нужно, чтобы «Клик» и расписания работали после перезагрузки Mac.
- **Тихие часы** — в это время Klick не говорит и не присылает уведомления, результаты остаются в истории.
- **Оформление** — светлое, тёмное или как в системе.

## 7. Что проверить в 0.2.10

Главное в этой версии — голосовой разговор подключается через сервер Klick. Он должен работать и там, где сервис OpenAI недоступен (например, в Беларуси). Слово «Клик» по-прежнему распознаётся на самом компьютере. Отмечайте, что проверили, а о том, что не сработало, напишите (раздел 8).

- [ ] Установка, вход и разрешения прошли без проблем (на Windows — и предупреждение «Система Windows защитила ваш компьютер»).
- [ ] Голосовой разговор подключается: скажите «Клик» или нажмите ⌘⇧J (на Windows Ctrl+Shift+J) — Klick отвечает голосом. Если видите ошибку, перепишите её текст дословно и напишите, в какой вы стране и включён ли VPN.
- [ ] С включённым «Слушать „Клик“» на «Клик, открой почту» Klick откликается и делает. Попробуйте 5 раз, с разного расстояния.
- [ ] Поговорите рядом 5 минут о чём-нибудь другом: Klick не должен просыпаться сам.
- [ ] Голосом отправьте себе или другу сообщение в WhatsApp или Telegram: пока задача идёт, Klick не говорит «Ещё работаю…», а сообщение доходит.
- [ ] Напишите задачу в окне Klick и через ⌘⇧Space: обе выполняются.
- [ ] Во время длинной задачи нажмите ⌘⇧X: задача останавливается.
- [ ] В «Настройки» → «Лимиты» одна строка «Неделя», без «Текущие 5 часов».
- [ ] Процент в «Лимитах» растёт понемногу: запишите, сколько процентов съела одна типичная задача.
- [ ] Короткий ответ («привет», «как дела?») приходит быстро: запишите, за сколько секунд.

## 8. Если что-то не так

Задача зависла — нажмите ⌘⇧X (на Windows Ctrl+Shift+X). Не помогло — закройте Klick (на Mac ⌘Q, на Windows значок Klick у часов → «Выход») и откройте снова.

О каждой проблеме напишите тому, кто прислал вам ссылку:

1. Версия Klick (0.2.10) и какой у вас компьютер: Mac с чипом Apple, Mac с Intel или Windows.
2. Что вы сказали или написали — дословно.
3. Что ожидали и что сделал Klick.
4. Примерное время, когда это случилось.
5. Скриншот, если на экране была ошибка (Mac — ⌘⇧5, Windows — Win+Shift+S).
6. Журнал Klick, файл `klick.log`:
    - Mac: в Finder нажмите ⌘⇧G и вставьте `~/Library/Application Support/PC Assistant/logs`;
    - Windows: нажмите Win+R (окно «Выполнить», не командную строку), вставьте `%APPDATA%\PC Assistant\logs` и нажмите Enter — откроется папка с файлом.

В журнал не попадают пароли и ключи. Сам Klick его никуда не отправляет: файл остаётся на вашем Mac, пока вы его не пришлёте.
