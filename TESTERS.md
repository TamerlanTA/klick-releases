# Klick 0.2.27 — инструкция для тестировщиков

Обновлено 26.11.2026, версия 0.2.27.

Klick — ИИ-ассистент, который сам выполняет задачи на вашем компьютере: по тексту или голосом. Версия 0.2.27 — для Mac и Windows. Ниже — как её поставить, подключить и с чего начать.

## 1. Скачать и установить

Скачайте файл для своего компьютера. Какой у вас Mac: меню  → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

| Компьютер | Файл |
| --- | --- |
| Mac с чипом Apple (M1, M2, M3, M4) | [Klick-mac-arm64.dmg](https://github.com/TamerlanTA/klick-releases/releases/download/v0.2.27/Klick-mac-arm64.dmg) |
| Mac с процессором Intel | [Klick-mac-x64.dmg](https://github.com/TamerlanTA/klick-releases/releases/download/v0.2.27/Klick-mac-x64.dmg) |
| Windows 10 и 11 (64-бит) | [Klick-Setup.exe](https://github.com/TamerlanTA/klick-releases/releases/download/v0.2.27/Klick-Setup.exe) |

Страница версии: [Klick 0.2.27](https://github.com/TamerlanTA/klick-releases/releases/tag/v0.2.27). Уже стоит прежняя версия — поставьте 0.2.27 поверх: вход, память и чаты сохранятся.

**Windows.** Запустите `Klick-Setup.exe`. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае»: сборка пока без цифровой подписи. Klick установится без прав администратора и откроется сам.

**Mac:**

1. Откройте скачанный `.dmg` и перетащите **Klick** в папку **«Программы»**. Если Klick уже стоит, замените старую версию: вход, память и чаты сохранятся.
2. Откройте Klick из «Программ». macOS спросит, открыть ли приложение, загруженное из интернета, — нажмите **«Открыть»**. С 0.2.13 Klick подписан и проверен Apple, «Всё равно открыть» в настройках больше не нужно.
3. Если macOS спросит пароль от Mac для «Klick Safe Storage», введите его и нажмите **«Разрешить всегда»**. Так бывает один раз при переходе со старой версии: Klick читает своё сохранённое подключение. Если нажать «Запретить», Klick попросит подключить компьютер заново (раздел 2) — память и чаты останутся.

## 2. Войти

При первом запуске Klick покажет окно «Привет, я Klick».

1. Нажмите **«Войти через браузер»**. Откроется сайт [sayklick.app](https://www.sayklick.app).
2. Войдите через Google или по почте. Если аккаунта нет, нажмите «Создать аккаунт».
3. Нажмите **«Подключить»**. Браузер спросит, открыть ли Klick, — разрешите. Klick подключится сам.
4. Если Klick не открылся, скопируйте код со страницы и вставьте его в Klick через **«Вставить код из браузера»**.

Есть приложение Klick на телефоне? Тогда можно иначе: в телефоне «Компьютер» → «Подключить», а в Klick на Mac — **«Есть код из приложения Klick»** и 6-значный код. После этого задачи можно давать и с телефона.

Новый аккаунт получает бесплатный доступ до открытия оплаты.

## 3. Разрешения

**Windows:** отдельных разрешений не нужно. Если Klick не слышит вас, включите доступ к микрофону для приложений: «Параметры» → «Конфиденциальность и защита» → «Микрофон».

**Mac:** без трёх разрешений Klick не сможет слышать вас, видеть экран и работать с приложениями. Все три включаются в **Системные настройки → Конфиденциальность и безопасность**.

| Разрешение | Зачем |
| --- | --- |
| Микрофон | голосовые команды и слово «Клик» |
| Универсальный доступ | управлять мышью, клавиатурой и приложениями |
| Запись экрана | видеть, что на экране |

- Klick сам попросит нужное. Если чего-то не хватает, в его окне появится плашка с кнопками, которые открывают нужные настройки.
- После того как включили разрешения, нажмите «Перезапустить Klick» или закройте и снова откройте его.
- При переходе с 0.2.12 или старше macOS один раз сбросит «Универсальный доступ» и «Запись экрана»: у Klick появилась подпись Apple, и для macOS он выглядит новым приложением. Если Klick в списке уже включён, но не работает, удалите его из списка кнопкой «−» и добавьте заново. Следующие обновления разрешения сбрасывать не должны.

## 4. Как давать задачи

Задачу можно написать или сказать обычными словами, как человеку. Klick сам решает, что открыть и куда нажать, и показывает ход работы.

- **В окне Klick.** Нажмите «Новый чат», напишите задачу и нажмите Enter. В чате можно уточнять: «а теперь отправь ему ещё раз».
- **Быстрая команда из любого места.** Нажмите ⌘⇧Space, напишите задачу в маленькой строке. Ответ Klick может произнести голосом.
- **Голосом через «Клик».** Включите «Настройки» → «Слушать „Клик“». Теперь скажите «Клик» и задачу, например «Клик, открой почту». Работает и при закрытом окне.
- **Разговор без слова «Клик».** Нажмите ⌘⇧J или «Голосовой ассистент» в левом нижнем углу окна. Чтобы закончить, попрощайтесь: «Ладно, пока».

Перед действиями, которые нельзя отменить (отправить, удалить, опубликовать), Klick спрашивает подтверждение. Ответьте «да» или «нет» — голосом или кнопкой. Задачи идут по одной: новая ждёт, пока закончится текущая.

| Mac | Windows | Что делают |
| --- | --- | --- |
| ⌘⇧Space | Ctrl+Shift+Space | быстрая команда |
| ⌘⇧J | Ctrl+Shift+J | голосовой разговор |
| ⌘⇧X | Ctrl+Shift+X | остановить текущую задачу |
| ⌘N | Ctrl+N | новый чат |

Ниже в тексте клавиши указаны для Mac; на Windows вместо ⌘ — Ctrl.

## 5. Примеры задач

Начните с простого, потом пробуйте задачи из своей работы.

| Что нужно | Как сказать или написать |
| --- | --- |
| Сообщение | «Клик, напиши Алие в WhatsApp: буду через полчаса» |
| Найти в интернете | «Найди три кофейни рядом с метро Алатау с рейтингом выше 4,5» |
| Открыть и настроить | «Открой почту и покажи непрочитанные письма» |
| Таблица | «Сделай таблицу Excel с расходами за неделю и сохрани на рабочий стол» |
| Презентация | «Сделай презентацию из 5 слайдов про наш новый продукт» |
| Картинка | «Нарисуй баннер для инстаграма с кофе и круассаном» |
| По расписанию | «Каждое утро в 9:00 присылай погоду и курс доллара» |
| Запомнить | «Запомни: мою жену зовут Айгерим, она в WhatsApp как «Айгерим»» |

Чем точнее задача (кому, что, куда сохранить), тем быстрее и дешевле она выполняется.

## 6. Разделы окна и настройки

Слева в окне Klick — разделы, внизу — «Настройки».

| Раздел | Что там |
| --- | --- |
| Задачи | всё, что Klick делал: из чата, голосом, с телефона, по расписанию |
| Проекты | большие задачи из нескольких шагов: бриф, шаги, проверенные результаты |
| Расписания | повторяющиеся задачи (каждое утро, по будням) и ваши быстрые команды |
| Навыки и память | что Klick знает о вас и чему научился; лишнее можно удалить |
| Чаты | ваши разговоры с Klick, есть поиск |

В «Настройках» стоит сразу заглянуть в эти пункты:

- **Лимиты** — сколько израсходовано за неделю. Лимит обновляется в понедельник в 00:00 (по Алматы).
- **Слушать «Клик»** — включает пробуждение по слову «Клик».
- **Голос и темп речи** — выберите голос Klick и нажмите «Послушать». Голос можно сменить и словами: «Клик, смени голос».
- **Как к вам обращаться** — имя, которое Klick использует в разговоре.
- **Запускать при входе** — нужно, чтобы «Клик» и расписания работали после перезагрузки Mac.
- **Тихие часы** — в это время Klick не говорит и не присылает уведомления, результаты остаются в истории.
- **Оформление** — светлое, тёмное или как в системе.

## 7. Что проверить в 0.2.27

Новое в 0.2.27: если Microsoft Edge спрашивает «Разрешить удалённую отладку?», Klick просит нажать «Разрешить» и ждёт; в браузере работают сочетания клавиш (Ctrl+H и другие) и F1–F12, а скачивание файла не ломает задачу; программу без окна (Почта, Safari) Klick открывает сам; долгий запуск программы на Windows больше не кончается ошибкой; на вопрос «как мне это сделать?» Klick объясняет шаги и предлагает сделать сам; оборванный ответ модели больше не обрывает задачу. Сюда же входит всё из 0.2.27: новая страница настроек по разделам, точнее подсказки в браузере Klick. С 0.2.13 Klick обновляется сам, кнопкой «Перезапустить и обновить».

Сохраняется защита из 0.2.24: у каждого аккаунта на компьютере свои чаты, память и задачи — история из прошлой версии переносится в ваш аккаунт сама (если компьютер не был подключён, Klick предложит «Перенести в этот аккаунт»); «Отключить компьютер» работает надёжнее; пока Klick не услышал «Клик», речь не уходит на сервер; вложения не теряются; приложение проверяет, что его файлы не изменены. Сюда же входит всё из 0.2.23: Klick делает дела сам, «Что сделал Klick» с «Отменить», настройки самостоятельности словами, утренний план, режимы вопросов. С 0.2.13 Klick обновляется сам, кнопкой «Перезапустить и обновить»; с 0.2.12 и старше на новую версию нужно перейти вручную, последний раз. Отмечайте, что проверили, а о том, что не сработало, напишите (раздел 8).

- [ ] «Браузер» в боковой панели: откройте сайт, создайте вторую вкладку, переключитесь между ними. Кнопка глобуса в чате показывает браузер рядом.
- [ ] Браузер не закрывает настройки и диалоги Klick: при их открытии страница уступает место интерфейсу.
- [ ] Голос: произнесите длинную мысль с паузой — реплика остаётся в чате и получает ответ.
- [ ] Mac: новая версия поставилась поверх старой и открылась кнопкой «Открыть», без «Всё равно открыть» в настройках.
- [ ] Mac: что спросила macOS при первом запуске — пароль для «Klick Safe Storage», разрешения заново. Напишите, что именно появилось.
- [ ] После установки Klick остался подключён к аккаунту: входить заново не пришлось. Если пришлось — напишите.
- [ ] «Универсальный доступ» и «Запись экрана» после повторного включения работают: Klick видит экран и нажимает в приложениях.
- [ ] Windows: новая версия поставилась поверх, Klick остался подключён.
- [ ] На вопрос «Разрешить?» ответьте своими словами (например, «не этот файл»): Klick не пишет «разрешение отклонено», учитывает ваши слова и спрашивает снова.
- [ ] Обычная задача («покажи, что лежит в папке Загрузки») и голос (⌘⇧J, на Windows Ctrl+Shift+J) работают как раньше.
- [ ] Нажмите «Стоп» посреди задачи и сразу дайте новую: новая выполняется.
- [ ] Windows: в настройках и на кнопках горячие клавиши написаны как Ctrl+Shift, а не значками Mac; текст не вылезает за края окна.
- [ ] Голос: переключатель «Слушать „Клик“» выключается сразу, и микрофон после этого не горит. У шара есть кнопка, чтобы выключить микрофон в разговоре.
- [ ] Голос: длинная первая фраза слышна целиком, а свои ответы Klick не принимает за ваши слова.
- [ ] «Открой Blender» (или другую программу): задача заканчивается «Готово», а не «не подтверждено, сверьте в Истории».
- [ ] Mac: если открыть Klick прямо из образа .dmg или из «Загрузок», он предложит переместиться в «Программы».
- [ ] «Уведомления» в боковой панели: синяя метка показывает число непрочитанных, список такой же, как в приложении на телефоне. Прочитали на компьютере — на телефоне тоже прочитано.
- [ ] «Настройки» → «Аккаунт и безопасность»: видно, где выполнен вход (телефон, сайт). «Выйти» на одном из них работает, компьютер остаётся подключённым.
- [ ] Ответ голосом: дайте задачу, где Klick спросит «Отправить?» (например, написать сообщение). Скажите «Клик» или нажмите «Ответить голосом» под вопросом: Klick прочитает вопрос и текст сообщения, ответьте «да» или «нет».
- [ ] Файлы в чате: приложите скрепкой фото и PDF (или перетащите их в окно чата) и спросите, что в них: Klick отвечает по содержимому. Под сообщением видно, какие файлы приложены, и по нажатию файл открывается.
- [ ] «Настройки» → «Сервисы»: открывается отдельная страница «Подключения» с разделами и логотипами, как в телефоне. «Подключить» открывает вход в браузере; после возврата в Klick сервис отмечен «Подключено».
- [ ] Островок: сверните окно Klick. У верхнего края экрана появляется островок: что Klick делает, время задачи, микрофон и «Стоп». Разверните окно — островок уходит.
- [ ] Островок: нажмите на него — открывается маленький чат с последними сообщениями. Напишите задачу и нажмите Enter: Klick её выполняет, а островок не мешает ему нажимать и печатать.
- [ ] Островок: дайте задачу, где Klick спросит «Отправить?». Вопрос с кнопками появляется в островке сам, ответ кнопкой работает.
- [ ] Островок: перетащите его в другое место, сверните окно ещё раз — он стоит там, где вы его оставили. Выключить можно в «Настройки» → «Островок, когда окно свёрнуто».
- [ ] Новый дизайн: лицо Klick в окне показывает, что он делает — свободен, работает, ждёт вас, готово. Тёмная тема графитовая. Текст нигде не вылезает за края и не налезает друг на друга.
- [ ] Windows: «Открой Блокнот и напиши привет». Klick пишет текст в Блокнот сам, без снимков экрана и движений мыши, и один раз спрашивает «Разрешить в … до конца этой задачи?».
- [ ] Один вопрос на программу: задача из нескольких шагов в одной программе (например, «открой Excel и впиши в первую строку 1, 2, 3»). Вопрос «Разрешить в … до конца этой задачи?» появляется один раз. Если в задаче есть отправка сообщения человеку, её Klick спрашивает отдельно.
- [ ] Windows: Telegram или WhatsApp для Windows — «напиши в Telegram Ане „привет“». Klick находит чат, вставляет текст и перед отправкой спрашивает «Отправить?».
- [ ] Напоминания: «напомни через 2 минуты попить воды». Через 2 минуты напоминание появляется на компьютере и в приложении на телефоне. «Отмени напоминание про воду» его отменяет.
- [ ] Если управление вашим Chrome недоступно, Klick продолжает в своём браузере без настройки Chrome. Входы на сайты в браузере Klick отдельные; пароли и коды вводите сами.
- [ ] Стоит 0.2.13–0.2.20: в окне Klick появится «Скачиваю обновление…», затем «Перезапустить и обновить». После нажатия Klick закроется и сам откроется уже новой версии, вход и разрешения на месте. Если видите «Само обновиться не вышло», напишите.

## 8. Если что-то не так

Задача зависла — нажмите ⌘⇧X (на Windows Ctrl+Shift+X). Не помогло — закройте Klick (на Mac ⌘Q, на Windows значок Klick у часов → «Выход») и откройте снова.

О каждой проблеме напишите тому, кто прислал вам ссылку:

1. Версия Klick (0.2.27) и какой у вас компьютер: Mac с чипом Apple, Mac с Intel или Windows.
2. Что вы сказали или написали — дословно.
3. Что ожидали и что сделал Klick.
4. Примерное время, когда это случилось.
5. Скриншот, если на экране была ошибка (Mac — ⌘⇧5, Windows — Win+Shift+S).
6. Журнал Klick, файл `klick.log`:
    - Mac: в Finder нажмите ⌘⇧G и вставьте `~/Library/Application Support/PC Assistant/logs`;
    - Windows: нажмите Win+R (окно «Выполнить», не командную строку), вставьте `%APPDATA%\PC Assistant\logs` и нажмите Enter — откроется папка с файлом.

В журнал не попадают пароли и ключи. Сам Klick его никуда не отправляет: файл остаётся на вашем Mac, пока вы его не пришлёте.
